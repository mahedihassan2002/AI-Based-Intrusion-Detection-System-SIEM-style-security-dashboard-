# AI-Based-Intrusion-Detection-System-SIEM-style-security-dashboard-
Detects cyber threats in real time using three ML models — Isolation Forest, XGBoost, and an Autoencoder — trained on 40,000 network records. Classifies traffic as DDoS, Malware, or Intrusion. Features a SIEM-style dashboard and live packet capture via Scapy.
